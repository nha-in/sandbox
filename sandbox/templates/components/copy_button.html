{% comment %} Icon button that copies `value`. `label` names the value for screen readers. Ported from ohcnetwork/experience. The behaviour lives in the delegated handler in static/js/project.js, not here, so any number of these on a page cost one listener. Progressive enhancement has a limit here: with JavaScript off this button does nothing, so it must never be the *only* way to get at a value. The value is always rendered as selectable text beside it. {% endcomment %} {% load i18n %}
